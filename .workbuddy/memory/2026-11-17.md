## 学生作业详情页三处反馈修正

- **组长提交 403 的真因**：`ScoringMapper.studentLeadsGroup` 原先要求 `team_status IN ('CONFIRMED','COMPLETED')`，但学生自建小组写入 `'FORMING'`（`insertStudentGroup`）、教师导入才写 `'CONFIRMED'`，且仓库中没有任何 FORMING→CONFIRMED 流转代码，导致前端显示「我是组长 · 可编辑」而后端必拒绝。改为 `team_status NOT IN ('DISSOLVED','ARCHIVED')`，保留 `leader_student_id` + `assignment_id` 校验，只放行有效进行中的小组；已确认 `studentGroupMembers` 返回 `studentId`、`insertStudentLeader` 与 `leader_student_id` 一致，故该门控是唯一阻塞点。
- 新增 `ScoringServiceWorkloadAccessTest`（3 例）：组长通过权限校验继续走后续校验、非组长 403、反射断言 `@Select` 不再排除 FORMING。
- 右栏「提交清单」与「我的小组」等高：`.side` 加 `grid-auto-rows: 1fr`。
- 评分标准恢复「每个评价分支一整行」：`.rubric-list` 改单列 + 行分隔线，名称与权重同行、描述整行、底部渐变权重条（还原 HEAD 视觉），移除 `repeat(auto-fit, minmax(210px,1fr))` 多列卡片网格；模板补回 `<i><em :style="width: weight%">`。
- 验证：`mvn test` 70 通过 / 5 skipped（新增 3 例），`npm test` 17 通过，`npm run build` 成功。未做浏览器实机检查。
